# Local .memory/ for reality-merge

This directory contains project-specific rules, principles, and configurations for the `reality-merge` repository.

It follows the "Fractal Memory" principle, inheriting concepts from the parent `.memory/` directory in the `gemini` repository, as well as the `.memory/` concept shared at the [diy-make/reality-merge](https://github.com/diy-make/reality-merge) repository.
